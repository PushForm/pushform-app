# Documents and saving

## Open, create and return to documents

Sign in to use PushForm. Home shows your cloud document library, where you can create a model or a Layout drawing and open saved files.

Click the **PushForm** logo or name in an editor to return Home. Returning Home keeps your documents open. Use **Continue working** to return to one, or choose its document tab when you are in an editor.

## Save status

Working changes save locally on this device. Choose **Save version** in the header, Main menu, or command search to create a private cloud checkpoint. The dialog shows the next revision number and accepts optional change notes. Saving unchanged content reuses the current cloud revision. The status distinguishes local checkpoint progress from the last successful cloud version. Local storage failures are reported; another device opens the last cloud version, not later local changes.

**Share with the community** starts unchecked. Check it and choose **Save & continue to publishing** to review the saved snapshot for Commons. A separate Publish confirmation makes it public. Cancelling publication retains the private cloud version. Private change notes are not published.

If a save conflicts with a newer cloud revision, automatic retries stop. **Save As…** lets you save a separate file.

## Refresh the page

A refresh returns you to your active document when this browser tab can restore its saved session. Refreshing while on Home keeps you on Home. The remembered session belongs to your signed-in account; another account does not receive your documents.

If browser storage is unavailable or the saved session cannot be read, PushForm opens Home instead.

## Wait for a large document to open

While a document opens, PushForm shows a busy cursor and a progress bar with its name and loading stage. Large files can spend time downloading, being read, or preparing the workspace. The bar keeps moving when an exact percentage is unavailable. It disappears when opening finishes or fails; an error message explains a failed open. An already-open file simply switches to its tab.

## Wait while a refreshed workspace restores

After a refresh, PushForm shows **Restoring your workspace…** before reading the saved documents. It shows the current document and a document count when available, then **Preparing your documents…** while the workspace is built. The busy cursor remains until the workspace appears. If the saved workspace is unavailable, PushForm opens Home.
