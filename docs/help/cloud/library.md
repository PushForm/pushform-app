# Your cloud library

## Find a saved document

On Home, browse your projects or use **Owned by me** and **Recently opened**. Search and project filters help narrow the files. Recently opened is history for your account in this browser, not another copy of each document.

Use a file's Open action to edit it. Grid view can show document thumbnails; a missing thumbnail does not mean the file is empty.

## Create a project, folder or document

Use Home's create actions. Give a new document a name and choose its project and folder. With no explicit project, the document uses your Documents project.

Open a project to browse its folders. **New folder** creates a folder in the current location. A folder path shows where you are. Project-wide search can show files from different folders.

## Import several files into the library

Choose **Import files** on Home. Drop files or choose several, select the destination project and folder, then continue. The dialog converts and saves each supported file in order and reports success or a reason for failure.

This import saves to the library without opening editor tabs. Supported types include SketchUp, LayOut and common model formats such as OBJ, COLLADA, STL, glTF and DXF. Unsupported extensions are reported as skipped.

## Understand import notes

The import results identify each saved file and its conversion notes. A failed file does not prevent other valid files in the batch from being saved. Check units and supported-content notes when geometry looks different from its source.

Importing from Home is different from using Import inside an open editor. Choose the workflow according to whether you want a new library file or content in the current document.

## Understand privacy and access

Your current cloud projects, file metadata and document contents are private to your account. Saving does not publish a file or share it with another account.

An inaccessible file or unavailable source reports an error. Knowing a file's name or identifier does not grant access. Do not assume team sharing or public publishing is available because a document has been saved.

## File previews and offline use

Home’s grid and the Files panel load previews from this device’s cache first, then the cloud. If a preview is missing, PushForm generates it in the background, one at a time. You can keep working while previews appear.

Cached previews remain available offline. Newly generated previews are cached immediately and uploaded when connected; pending uploads survive a reload when browser storage is available. A missing preview needs either a matching saved document already open locally or access to its cloud file. Caching a preview does not download the document itself for offline editing.
