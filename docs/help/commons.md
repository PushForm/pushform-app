# Download models from Commons

PushForm Commons is a community model catalog with its own website. Browse models, search by name or description, and filter by category or license. The commercial-use filter includes models only when every listed license explicitly permits commercial use; read all listed conditions before reuse.

Open a model to see its original creator next to the title. Source information, licenses and required credits are grouped under **Licenses & attribution**. When files are available, choose **Download ZIP** next to a filename. The package contains the unchanged original in `files/`, an `ATTRIBUTION.json` record and a README. Keep required credits and license notices with reused files. A free download does not remove license conditions.

## Browse featured projects and collections

The Commons website shows **Featured** above search and filters, three projects at a time. Use **Next featured** and **Previous featured** to browse more. This section mixes individual models with collections of related models. A collection card has a mosaic cover and a **Collection** label; opening it shows the curator, description and its available models. Open any model in the collection to read its own license and credits or open it in PushForm.

Use the **Models** and **Collections** tabs below Featured to search the library. Filtering changes those results while the featured selection stays in place. Collections match their titles, descriptions, curators and member model names; category and license filters include collections with a matching model. **Commercial use permitted** includes a collection only when all its available models explicitly permit commercial use under every listed license. Read each model's conditions before reuse.

## Create and manage collections

Any signed-in PushForm user can create collections. Choose **New collection** or **My collections**, complete account setup if needed, then enter a title and optional description. The new-collection form defaults to **Public — visible in Commons**. Choose **Private — only you** before saving if you want a private collection. A public creator profile is optional; if you have an active public profile it appears as the collection's curator.

On a model page, **Save to collection** adds or removes that model using your collection checkboxes. **New private collection** creates a collection and saves the model into it in one action.

On your collection's page, choose **Edit collection** to change its details or visibility, remove models, and use **Move up** or **Move down** to set their order. To add models, open a model's page and choose **Save to collection**. The first four available models form its cover. Choose **Save collection** to apply your edits. You can keep up to 100 collections with up to 100 models each. If someone edits the same collection in another tab, reload before saving again; a failed save keeps your draft available for correction.

## Collection visibility and credits

Collections follow each model's current published version. Withdrawn models disappear from public collection views, and making a collection private removes it from public browsing and Featured. A collection does not transfer ownership or replace its models' licenses and credits. **Delete collection** removes only the collection; its models stay in Commons.

Public profiles show the creator's **Public collections** below their published models. Collections appear once they contain a model available in Commons. Open a collection card to browse its models. Private collections appear only in **My collections**, including when you view your own public profile.

## Feature a model or collection

Commons admins see **Feature** on published model pages and nonempty public collection pages. It adds the item to the end of Featured immediately; **Featured · Manage** opens the admin manager. Other accounts do not see this action.

In **Admin → Commons → Featured**, choose **Add featured item**, search for a model or collection, then feature it. **Move up** and **Move down** change the homepage order. **Remove** takes an entry out of Featured without deleting its model or collection. Entries that become private, empty or withdrawn stay in the manager as unavailable and are hidden from the homepage. If the list changed in another session, use **Reload list** before changing it again.

## Open a model in PushForm

Downloads require the catalog and model to remain available. If a file is unavailable, return to the catalog and try again later. Some builds may show metadata without configured downloads. A preview does not establish fabrication suitability or solid editability. Original file formats are listed; a download does not guarantee that PushForm can import that format. Extract the model file before using Open or Import. For supported files, choose **Open in PushForm** on the model page. It opens the web editor in another tab, continues through normal sign-in and initial account setup, and creates a separate model. Your current project stays open. Files without recorded units ask for units and up axis before opening. Unsupported originals remain available as downloads and may need conversion.

## Preserve creator notices

Model Info → Credits shows the original source, licenses, conditions and creator notices. Native saves retain those notices. Geometry and image exports from an attributed model are ZIP packages containing the exported file and attribution notices; keep the package together when sharing. In the editor, choose **Commons** directly below **Object browser** in the left menu bar to browse in a catalog tab. The Commons document tab has a books icon and an **×** close button. Close it to return to your design, and reopen it from the sidebar. Use the **Browse** and **My models** tabs to switch between the catalog and your publications. The model detail view places the preview beside its title, creator and main action, with licenses and credits below. A centered cube on a greenish-gray background appears while a preview loads or when no preview is available. The blue **Open in new tab** button opens a separate editable local copy directly and keeps your catalog search. Only files without recorded units need an extra step to choose units and, where applicable, up axis.

## Import into your current design

In a 3D design, the **Commons** books icon in the ribbon's **Import** group opens a picker for that design. Choose a model, inspect its licenses, and select **Import into** the named design. After download and validation, the picker closes and the model follows your cursor for placement. Only files without recorded units ask for units and, where applicable, up axis first. The bottom status bar shows the placement controls: click to place, press R to rotate 90 degrees, or Escape to cancel. Original licenses and credits are attached automatically when you place the model. One Undo removes the insertion and its added credits. Existing copies stay on the revision they imported. Unsupported representations explain why an import is unavailable.

## Your public profile

Choose **My profile** to sign in with your PushForm account. A new account completes the same private account setup and Terms of Use step used by the editor. Creating a public profile is a separate choice; it is not required to download models.

Choose a public handle and display name, then optionally add a bio and up to five links. Everything in this form is shown publicly once you save it. Your handle uses 3–32 lowercase letters, numbers or hyphens, starts with a letter and ends with a letter or number. Handles stay reserved and cannot be changed. Your private account name, email, company and projects are not copied into your public profile.

Saving takes you to your public profile page, at `/u/` followed by your handle (for example `commons.pushform.io/u/your-handle`). After that, **My profile** opens your public profile page. While you're signed in, your own profile page shows **Edit profile** at the right, just under the banner; choose it to change your profile. The page shows your chosen public fields and published models associated with your authorship. Imported models retain their original creator credit; uploading or curating someone else's model does not make you its author.

If your profile was hidden, saving it makes it visible again. If another tab changed the profile, reload the page before saving your changes. Older profile links continue to work and open the handle address.

## Add a profile picture and banner

After you publish your profile, the profile editor (**Edit profile** on your profile page) shows a **Profile picture** and a **Banner** section. Your banner runs across the top of your public profile page, and your profile picture overlaps its lower edge as a circle.

1. Choose **Upload profile picture** or **Upload banner** and pick a PNG or JPEG image up to 20 MiB and 8,192 pixels on each side.
2. Drag the image to position it and use the **Zoom** slider or the mouse wheel to zoom. With the crop area focused, the arrow keys move the image (hold Shift for larger steps) and plus and minus zoom.
3. Check the previews, then choose **Save profile picture** or **Save banner**. Choose **Cancel** to keep your current image.

Commons saves a profile picture at 512 × 512 pixels and a banner at 1500 × 500 pixels. Images with transparency stay PNG; others are saved as JPEG. A saved image must be 2 MiB or smaller. Very detailed transparent images are placed on a white background and saved as JPEG. While the image uploads, a progress bar shows its status, and Commons checks the image before showing it.

## Replace or remove your profile picture and banner

Saved images are public right away while your profile is visible; you don't need to save the profile form. Use **Replace profile picture** or **Replace banner** to choose a new image; the old one stops showing as soon as the new one is saved. Use **Remove profile picture** or **Remove banner** to take an image down. Hidden profiles don't show their images.

Earlier profiles may show a picture loaded from an address you entered. It keeps showing until you upload a profile picture, which then takes its place. You can no longer enter a picture address.

## Upload and publish a model

Choose **Upload model** in the Commons header. If you don't have a public profile yet, first choose a public handle and display name; models are published under that name.

1. Drag a model file into the box, or choose **browse for a file**. Commons accepts SKP, SKB, DAE, KMZ, OBJ, 3DS, STL, DXF, glTF, GLB, STEP, STP, PushForm (PF), FreeCAD (FCStd) and ZIP archives of these, up to 128 MiB. The model stays a private draft until you publish it.
2. The dialog moves straight to the details while the file uploads. The file row shows **Uploading** with a progress bar, then **Checking file**, then **Converting preview**, and finally **Preview ready** with the preview image. If you already have two previews converting, it shows **Waiting for converter** first.
3. Check the title, which starts as the file name, and choose a category and a license. A description and a cover photo (PNG or JPEG up to 8 MiB) are optional; without a cover photo, listings use the preview.
4. Tick the box confirming that you created the model, or have the right to share it and everything it includes under the license you chose. The Terms of Use require this.
5. Choose **Publish model**. You don't have to wait for the preview to finish.

Your changes save automatically as you type. **Save draft** or **Close** keeps the draft, file and preview under **My models**. If the upload fails, choose **Try again**. If a preview fails because of a converter problem, **Try again** starts a fresh conversion; a model that is too large or complex to preview can still be published.

### Licenses

- **Creative Commons Attribution 4.0** and the other Creative Commons 4.0 licenses (ShareAlike, NonCommercial, NoDerivatives and their combinations): others must credit you, with the conditions each name describes. The dialog shows a one-line summary of the license you choose.
- **Public domain (CC0 1.0)**: anyone may use the model for any purpose without credit.
- **Other (describe the terms)**: write your own terms, one per line. They appear on the model page as written, and the model counts as having unknown commercial-use permission.

## Manage your models

**My models** shows each of your models as a card with its preview, status and last change.

- **Edit** reopens the dialog. Changes to a draft save into that draft. Changes to a published model become a new draft that keeps its files, so nothing has to be uploaded again; the published version stays as it is until you choose **Publish changes**. **Replace file** uploads a new model file and converts it.
- **Delete draft** removes a model you never published. On a published model, **Discard changes** throws away its unpublished draft and keeps the published version.
- **View** opens a published model's page, and **Withdraw** takes it out of the library. Copies people already downloaded keep their licenses.

## Preview a model

Commons renders thumbnails from supported model geometry on its server; a contributor does not need to upload a screenshot. An optional uploaded PNG or JPEG is used as the listing image instead. Choose **Explore in 3D** on a model page to rotate the geometry, zoom, or reset the view. Drag to orbit, use the labeled controls, or focus the viewer and use arrow keys, plus/minus, and zero to reset. Previews are available without signing in; original downloads require your PushForm account and initial account setup.

Commons converts every format it accepts as soon as the upload is checked: native PushForm, STEP, FreeCAD, SketchUp (SKP and SKB), DXF, KMZ and mesh files (STL, OBJ, GLB/glTF, COLLADA, 3DS and model ZIPs). Drafts get previews too, visible only to you until you publish. It accepts originals up to 128 MiB for conversion and displays up to 12,000 triangles. It shows geometry and material colors, with no textures, annotations, recorded dimensions, units or fabrication suitability. Unsupported content and models over those limits show an unavailable preview; try **Open in PushForm** or download the original where supported. A failed image falls back to the generated thumbnail when possible.

## Wait for a generated preview

A new publication may show **Rendering preview…** while its server job waits or runs. Commons updates the image when rendering finishes. Identical files reuse cached geometry and thumbnails. An uploaded PNG/JPEG still takes precedence as the listing image. If a render fails, the model page explains the failure and retains its original-file and license information. Try **Open in PushForm** or download the original where supported.

FreeCAD previews use visible saved BREP shapes, without running document scripts or recomputing the model. Assembly links/group placements and files without stored shape geometry are not supported by this preview converter.

When several files are available, downloads put the native PushForm model first, then STEP and common exchange formats, with FreeCAD sources last. The preview also prefers the native model over source and notice archives. Downloads include attribution in a ZIP package; an archive download keeps a single `.zip` filename suffix.

Commons has no fixed limit on the total number of published models. Individual models still need supported files, complete attribution and redistribution rights, and must meet the file size limits.

## Featured creators

The Featured section highlights models, collections and creators. Choose a creator card to visit their public profile. Commons admins can choose **Feature** on a public profile, or use **Admin → Featured → Add featured item** and filter by **Creators**. Search by name or handle, then add the creator. Move and remove creators using the same controls as other featured items. Hidden or deleted profiles do not appear on the homepage.

Creators credited on imported models can also be featured without a Commons account. In the picker, **Credited creator** entries show their source library. Their pages list currently published models carrying those credits; they are not account profiles. The same creator name from different source libraries appears separately. Models linked to an account profile remain associated with that profile.

## Browse a large library

Commons and the editor’s Commons browser load a small first set of models, then add more as you scroll. The next two sets and their thumbnail images are prepared in advance for smoother scrolling. **Load more models** also works with a keyboard. If a later set fails, your current results stay visible and **Retry loading more** tries again. Search and filters cover the entire library, including models that have not appeared on screen yet.
