# PushForm Commons

Commons is a community model catalog with its own website. The first catalog browser is in development; the hosted library is not available yet.

When a catalog is available, use Search models, Category and License to find a starting point. Commercial use permitted shows only models whose listed licenses all explicitly permit commercial use. Other conditions can still apply.

Open a model to read its description, available formats, published revision, original source, licenses and creator credits. Keep those notices with any reused work. A preview image does not establish that a model is suitable for fabrication or editable as a solid.

This initial browser does not yet offer uploads, model-file downloads, 3D previews, insertion into a project, or social features. A catalog-loading error offers Try again; an empty catalog and a catalog that is not yet available have separate messages.
