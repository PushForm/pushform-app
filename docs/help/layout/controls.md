# Layout toolbar controls and their purpose

## Select, Lasso, Move, Rotate, Scale and Eraser

**Select** chooses objects for editing. **Lasso** chooses several objects with a drawn boundary. **Move** changes position, **Rotate** changes orientation, and **Scale** changes size. Use these Transform controls when existing artwork needs adjusting rather than drawing another object. **Eraser** removes eligible objects it is used on; Undo can restore an accidental edit.

Selection and editability matter: hidden or locked objects and layers can prevent an operation. Inspect the selection or layer before repeating the tool.

## Line, Bézier Curve and Freehand

These choices share the Line button in Draw. **Line** creates straight connected segments; use it for precise edges and closed outlines. **Bézier Curve** creates a path with editable anchors and handles; use it for smooth, deliberate curves. **Freehand** follows a drawn stroke and smooths it into an editable curve; use it for expressive outlines.

The small arrow exposes the other choices without committing any drawing. The tool's settings and status text explain its current placement step.

## Rectangle, Circle, Polygon and Arc choices

Use **Rectangle** for box-like shapes; its arrow offers rounded, bulged and lozenge variants. **Circle** is placed from a center and radius; **Ellipse** uses bounding corners. **Polygon** creates a regular straight-sided shape; its Sides setting controls the count. **Circumscribed Polygon** uses a radius to a flat side instead of a vertex.

Arc variants offer different placement points, and **Pie** closes an arc into a filled sector. Choose the variant that matches the reference points you already know.

## Offset, Fillet, Chamfer and Boolean controls

**Offset** makes a parallel copy without changing its source. **Fillet** rounds a corner; **Chamfer** bevels it. Use these Modify controls to derive geometry from an existing path.

The Boolean button offers whole-shape combinations and cuts. **Shape Builder** instead starts from selected paths and lets you keep, merge or remove individual bounded regions. Read the preview and Apply/Cancel controls before committing: these operations are different from ordinary selection.

## Text, Label and Dimension

Use **Text** for ordinary writing on the page. Use **Label** for text with an arrow and leader pointing to something. Use **Linear Dimension** for a measured distance and **Angular Dimension** for an angle.

These Annotate controls explain existing drawing content. Changing annotation text or its placement is different from resizing the measured object.

## Table, Import and Model View

These buttons are in Insert. **Table** creates editable rows and columns. **Import**, the image button after Table, adds a PNG, JPG/JPEG or SVG image file, or a DXF drawing, to the active page. **Model View** creates a framed view of an available 3D model.

Choose Import for a picture file; choose Model View when you need a camera view linked to a model. **Main menu → Import...** opens the same picker as the toolbar Import button.

## Presentation mode

**Presentation mode**, in Present, displays the drawing without normal editor controls. Use it for showing pages rather than changing geometry. Use **Export…** or **Print** when you need a separate output file or paper copy; presentation itself does not replace or export the document.
