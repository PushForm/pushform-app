# Delete and erase objects in Layout

## Delete or remove a drawing object

To delete something from the page, choose **Select**, click the object, then press **Delete** or **Backspace**. You can also right-click the object and choose **Delete** from its context menu. To remove several objects, select them together and press Delete once. Undo with **Ctrl+Z**, or **Cmd+Z** on macOS, restores the deletion.

Click the drawing canvas before using the shortcut if you were typing in AI Chat, a text field or the Object browser. Keys typed in chat stay in chat. Deleting an object does not require closing chat. A selected group is handled as a group.

## Erase an object with the Eraser tool

Choose **Eraser** in the toolbar's **Transform** section, or press **E** while the drawing canvas has focus, then click the object to erase it. This removes the object, rather than rubbing out pixels or trimming just the part under the pointer. Use Undo to restore an accidental removal.

For a specific selected object, Select followed by Delete is usually the shortest route. The toolbar's Eraser is a separate route; there does not have to be a Delete button in the toolbar or main menu.

## Troubleshoot locks, focus, vertices and cells

Locked objects or objects on locked layers cannot be deleted until unlocked. In path vertex editing, Delete or Backspace removes the selected vertex when at least two vertices can remain; press Escape to return to object selection before deleting the whole object. While table cells are active, Delete clears their text rather than removing the table. Finish cell or text editing and select the whole table or text object to remove it.

An object or group's context menu in **Object browser** also offers **Delete**. It is disabled when the object or its layer is locked; a group's deletion removes its unlocked members.
