# Import images into Layout

## Import a PNG, JPG, JPEG or SVG image

Click **Import** in the toolbar's **Insert** group, just after Table, and choose your **PNG**, **JPG/JPEG**, or **SVG** file. You can also use **Main menu → Import...** or search for **Import** in command search. These routes open the same file picker.

Import embeds the picture centered on the active page and selects it. Drag the selected image to position it; use its frame handles to resize and hold Shift to keep its proportions. You can rotate it with Rotate or the available frame controls. The picture is kept with the drawing when saved. Undo removes the import.

Use a visible, unlocked drawing layer. Cancelling the file picker changes nothing. You do not need a new model document, an account-wide import, or a feature request to place a picture on a Layout page.

## Choose Import or Paste for an image

Use **Import** when the picture is a file on your computer. Use **Paste** when you already copied picture data in another application. Layout's file picker accepts SVG, PNG and JPEG images, plus DXF drawings; clipboard image support can include additional formats the browser decodes.

Importing SVG places the original as an embedded image. Pasting supported SVG artwork instead creates editable vector objects. Choose the embedded-image route when preserving the original appearance matters, or the editable-vector route when you need to change individual paths.

## Find and use the Import control

**Toolbar → Insert → Import** is the picture-icon button after Table. **Main menu → Import...** is the menu alternative. They are the same action, so choose whichever is easier to reach. **Open...** opens a document; **Import** adds content to the page you are already editing.

After clicking Import, choose a supported file and confirm the picker. The image is added only after that choice is successfully read. Merely clicking the button does not mean that a picture has already been placed.

## Troubleshoot an image import

If the image format is not offered, use PNG, JPG/JPEG or SVG, or copy supported image data and Paste. If the file cannot be read, check its actual format and try a readable copy. Switching pages or closing the document during loading cancels the pending insertion.

If you cannot edit the result, check the current layer's visibility and lock state. A missing result in help search does not mean image importing is unavailable; Import is the existing image-file workflow in Layout.
