# Pages and layers in Layout

## Manage pages

Open the **Object browser** from the left menu bar. Pages contain layers and objects. Use a page's context menu to add a page after it, duplicate it, or delete it. New pages take the document's paper size and margin.

Click a page to work on it. Drag page entries to change their order. Page-specific text fields and exported page order follow the document's page order.

## Choose a drawing layer

In the Object browser, expand the active page and choose an editable layer for new drawing. A pencil marks the current drawing layer. Hidden or locked layers cannot receive normal drawing edits.

Use a layer's context menu to add, duplicate, rename, delete or configure it. The eye changes visibility and the lock prevents edits. Drag layers to adjust their drawing order.

## Show a layer on every page

Open a layer's context menu and use **Show on Every Page** for repeated material such as a title block. Shared layer content appears on pages using that layer, so editing it affects those pages.

Check whether the content should be shared before changing it. Duplicating individual page objects is different from using an every-page layer.

## Work with browser objects

Expand the page and layer to find an object. Clicking selects it. Double-click its name, or press F2 on a focused item, to rename it. Use the eye and lock controls for visibility and editability.

A selection made on the page expands its ancestors and reveals it in the browser. Arrow keys navigate the tree while it has focus; Escape closes the panel rather than reaching a drawing tool.

## Set paper, units and grid

Open **Document Settings** in the Object browser. Configure the paper size, orientation, margin, units and grid there. Tool-specific settings live separately in the temporary pane at the top of the right-side panel.

Choosing a paper size sets it in landscape. Use **Orientation** to turn the page to portrait. A US size such as Letter also switches the page size, the grid and drawing values to inches; an international size such as A4 switches them to millimeters.

**Grid units** decide the units of drawing values: the fields you type sizes into while drawing, and new dimensions. With the grid in millimeters, drawing gives metric values. Changing the grid units rounds the grid size to a usual size in the new units, such as 1/4 in or 5 mm. **Page size units** change only how the page size and margin are shown.

Check paper size and export settings when you need a particular physical output scale.
