# Tables in Layout

## Create a table

Choose **Table** in Insert. Set the rows and columns in its temporary pane, from 1 to 100 each. Press on the page to set the first corner. Release without dragging to keep those counts, move the pointer to size the table, then click to place it.

You can choose counts while holding the mouse: drag horizontally to add columns and vertically to add rows. Release to lock the counts, then size and click to place. Measurements accepts width and height after the first corner. Escape cancels.

## Edit table cells

Clicking a table with Select selects the whole table for moving or resizing. Double-click an editable table to enter cell editing at that cell. In table edit mode, click a cell to select it; typing replaces its text. Double-click, F2, or Enter edits the existing text.

Use the table's available row, column, merge and formatting controls for structural edits. Finish or cancel the current cell draft before switching to an object transform. Resizing a table changes cell bounds without scaling the fonts.

## Paste a spreadsheet or HTML table

Copy cells in the source application and paste onto the Layout page. HTML tables and tab-separated text become native editable tables. Supported cell merges, text styles and HTML background colors are retained. Empty cells remain empty.

Pasted tables are centered on the active page and selected. Tables larger than 100 rows or 100 columns are rejected. Multiline text without tabs stays text rather than becoming a table.

## Paste text instead of a table

Use **Ctrl/Cmd+Shift+V** to paste without source formatting. On the page this creates a text box even when the clipboard contains tab-separated table data.

While editing an existing text object or table cell, paste operates in that editor rather than creating a separate page object.


## Resize, merge and format table cells

In table edit mode, drag a row's bottom edge or column's right edge to resize it. Edge grips keep boundaries reachable even around merged cells. The table frame grows or shrinks without scaling its fonts.

Drag across cells or Shift-click to select a range. Use Table properties to merge or unmerge it, insert or delete rows and columns, set sizes, space them equally, and format text or cell fills. Arrow keys move between cells; Shift+Arrow extends the range. Escape cancels a text draft, then reduces a range or exits cell selection in later steps.
