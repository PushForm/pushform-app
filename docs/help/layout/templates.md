# Layout templates

## Choose paper and page content

Choose **New Layout** in the Main menu or the document-tab **+** menu. In **Choose a Template**, pick **Paper**, **Storyboard**, or **Titleblock**, select a preview, and click **Create Layout**. You can also double-click a preview. **Cancel** or Escape leaves your current document alone.

Paper offers graph and plain paper. Storyboards include editable numbered frames; titleblocks include editable project, drawing, and sheet text. Graph Paper A4 Landscape is selected initially. If your browser's language/region is set to the US, Letter and Tabloid appear first within each paper group and in Titleblock; other regions show A3 and A4 first. All sizes remain available.

## Save your own Layout template

Open a Layout drawing and choose **Save as Template…** in the Main menu or command search. Choose a project, enter a file name, and click **Save Template**. You can create a project in the dialog if needed. This saves a private copy of all pages, content, and document settings; your current drawing keeps its own name and save destination. **Cancel** leaves it alone. If saving fails, retry from the dialog.

## Start a drawing from a saved template

Choose **New Layout**, then the **My Templates** tab immediately to the right of **Titleblock** to browse your saved templates by project in the same dialog. You can search or change pages there, or switch back to a built-in template tab. Select one and click **Create Layout**, or double-click it. You can also open a template from Home, where it has a distinct icon and a **Layout template** label.

Each use creates a new, untitled drawing with the template's contents and an empty undo history. It autosaves as an ordinary drawing in the template's project and folder. Edit and rename that new drawing as usual; the saved template stays unchanged.
