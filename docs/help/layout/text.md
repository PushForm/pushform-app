# Text and labels in Layout

## Add a text box

Choose **Text** in Annotate. Click for text whose box fits its content, or drag a rectangle for text that wraps within fixed bounds. Type your text, then leave the editor to finish. Dragging a text box does not automatically shrink the font or enlarge the box when it overflows.

Hold Ctrl or Cmd while dragging to place a centered text box with centered text. Otherwise, dragging left to right initially aligns left, and right to left aligns right.

## Format text

While editing, use the temporary formatting pane at the top of the right-side panel for font, size and supported text styling. Select a text range to format just that range. A text box's font size is independent of its frame size.

If part of the text disappears, increase the box's height or width, reduce the font size, or shorten the text. A fixed text box clips content that does not fit.

## Edit existing text

Double-click an editable text object to edit its content. Standard text selection, Copy and Paste operate inside the text editor while it has focus. Finish text editing before moving or resizing the object as a whole.

Pasting rich text can preserve supported fonts, sizes, colors, bold, italic, underline, paragraph alignment and line spacing. Ctrl/Cmd+Shift+V pastes plain text using the destination style.

## Add a label

Choose **Label** in Annotate. Click the arrow tip, the leader bend, then the text attachment point. The segment after the bend stays horizontal. A label combines editable text with its arrow or leader.

Select the label as an object to move or resize its text box. Keep its leader separate from the text frame when adjusting the annotation. Use the available label settings to change its supported style.

## Use page fields

Type **<PageName>**, **<PageNumber>**, **<PageCount>**, **<FileName>**, or **<CurrentDate>** in text for live fields. These resolve against the page where they are displayed, including every-page content. Typing **<** while editing opens matching field suggestions; use Up/Down and Tab to choose one. Unknown tags stay visible as typed.
