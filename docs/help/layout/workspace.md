# Working in Layout

## Find tools and their settings

Layout is the page-based drawing editor. Its toolbar is organized into **Transform**, **Draw**, **Modify**, **Annotate**, **Insert**, and **Present** groups. Buttons with small arrows offer related tools.

When the tool you choose has settings, a tool options bar floats over the top of the page view, between the side panels. For example, Polygon shows **Sides**, Table shows row and column counts, and Move shows **Copy**. Tools with nothing to set show no bar. Change a value and press Enter; lengths use the document's grid units. Press Ctrl+L (Cmd+L on a Mac) to move the keyboard into the bar and Escape to return to the page.

## Edit properties in the side panel

The right-side panel uses the same aligned fields and control styling as the 3D workspace. With nothing selected, the panel is titled **New Shapes** and sets the stroke, fill and arrows new shapes start with. Choosing a drawing tool clears the selection, so these changes always go to the next shape. Select one object to see its properties and **Arrange** controls for rotation, scaling, flipping, and stacking order. Flip and stacking-order actions appear in paired columns.

## Use the Object browser

Open **Object browser** from the left menu bar. It shows document settings, pages, layers, and objects. Expand an item to see what it contains. Clicking an object selects it in the drawing. A selected item can also be revealed when selected from the page.

## Pages, paper and grid

Use **Document Settings** in the Object browser to configure the document. New pages use the document's paper size and margin.

A new drawing starts with Snap to Grid enabled. Grid visibility and grid snapping are separate settings: hiding the grid does not turn snapping off. You can find **Toggle Grid** in command search.

## Objects past the page edge

An object that runs off the paper is still drawn in full: the part past the edge shows on the gray area around the page. It is drawn and highlighted the same way as the part on the paper, and moves with zoom and panning. Printing, exporting and presentation show only what is on the paper.

Your tools also work on the gray area around the page. You can draw past the edge or entirely off the paper, click an off-page part to select an object, and start a selection box there.

## Undo changes

Use Undo to reverse a document edit and Redo to restore it. Temporary previews do not change the drawing until you finish the operation.
