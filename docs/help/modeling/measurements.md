# Measurements in Modeling

## Enter an exact size

The Measurements box is at the right end of the Modeling status bar. Its label changes with the active tool, such as Length or Distance.

When you are not editing another text field, typing starts an entry in Measurements without clicking the box first. Press **Enter** to apply it to the active tool. Press **Escape** to discard it and cancel the operation.

## Use units

A length without a unit uses the model's current units. Include a unit to override that choice, for example **10mm**, **2.5m**, or **3'6"**.

Some tools take values that are not lengths, such as an angle or a scale factor. Those values are read as that tool's measurement.

## Keep Modeling and Layout instructions separate

Modeling works in 3D model units. Layout works on drawing pages and has its own tools and settings. Follow the guide for the editor you currently have open.
