# About PushForm and desktop updates

## Install on macOS

Open the downloaded `.dmg` file. In the PushForm window with the oak joinery background, drag **PushForm** onto **Applications**. When copying finishes, eject the disk image and open PushForm from your Applications folder.

## Find the app version

Run **About PushForm** from command search to see the running version and build information. This is useful when reporting a problem. Closing About returns to the document without changing it.

A browser refresh can load a newer web build. Your document session is restored when the browser's saved session is available.

## Read the license and find the source code

PushForm is open source. In **About PushForm**, choose **GNU GPLv3 license** to read the license in a new tab, or **Source code on GitHub** to open the public repository. Use Tab to reach the links, or Shift+Tab to move back. Escape closes About.

## Check for desktop updates

Run **Check for updates** from command search to open About and check immediately, or open **About PushForm** and choose **Check for updates**. About shows whether the check is running, the app is up to date, an update is ready, or the check failed. A newer update downloads and verifies before it is offered.

The check uses the channel shown in About. **Switch to Nightly** opts into nightly builds; **Switch to Stable** returns to stable releases. These controls require a desktop build with updates enabled and do not appear in the web editor.

## Install a desktop update

When the desktop notice says an update is ready, choose **Restart to update**. PushForm saves open documents before installing and restarting. **Later** hides the notice until the next start or a newer version.

If **Update required** appears when opening another document, choose **Restart and update**, or **Cancel** to return to the current workspace. A save or update error is shown in the prompt; resolve it before retrying. Do not close the application while a save is still failing. These restart controls are for the desktop app, not the web editor.
