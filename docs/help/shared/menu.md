# Main menu actions and alternatives

## Home, New Model and New Layout

Click the **PushForm logo/name** to return to your cloud library while keeping open documents available. Home is not in the Main menu. **New Model** creates a 3D modeling document. **New Layout** starts a page-based drawing through its template choice. The document-tab **+** button also offers new document types.

Choose the document type for the work: model geometry in Modeling, or page drawings and annotations in Layout.

## Open and Import are different

**Open…** opens a document or supported source file as a document to work on. **Import...** adds supported content to the editor you are currently using.

In **Layout**, Main menu → Import... and the toolbar's Insert → Import button open the same picker for SVG, PNG, JPG/JPEG images and DXF drawings. Imported pictures are embedded in the active page. In **Modeling**, Import adds supported models or picture files in the current modeling context. Home's **Import files** is a separate batch workflow that saves new library documents without opening them.

## Save and Save As

Cloud-connected documents save automatically, and the header shows the current save status. **Save** writes through the document's file-save flow. **Save As…** creates a separate cloud document, or opens the local save flow in installations without autosave.

**Save As…** also lets you resolve a conflict by creating a separate library document without overwriting another revision.

## Export and Print

**Export…** opens one format selector with options for the active document type. Choose the format according to what the destination needs: a native editable copy, a model exchange file, a page picture, or another supported drawing output. For a native copy, choose **PushForm Model (.pf)** or **PushForm Layout (.pfl)**, then **Export…**. Native export includes the entire document and keeps its cloud destination and saved state. Export does not replace the open native document.

**Print…** is a Layout main-menu action, also reached with Ctrl/Cmd+P. It opens print setup and then the system print dialog. Use paper size and Actual size/100% settings when physical scale matters.

## Find the same action with command search

Use Ctrl/Cmd+K and type a visible action name such as **Import**, **Export**, or **Print**. Search reflects the current editor and whether the action can run. A toolbar button, menu entry and command-search result can be different routes to the same operation, rather than three different capabilities.

## Rename an open document

Double-click the document name in its open tab and type a new name. Press Enter or click outside the field to apply it; press Escape to cancel. Cloud documents save the new name automatically. Leave the field empty to keep the previous name.

## Save As and pane commands

Choose **Save As…** from the Main menu or command search to save a separate cloud document with a name and destination. **Save** is also available in command search and saves pending changes. **Export…** with the native file type keeps a portable editable copy on your computer. Without cloud autosave, Save As uses the local file save flow.

Search for **AI Chat** or **Object browser** to toggle that pane. Each command has the same icon as its button in the left menu bar.
