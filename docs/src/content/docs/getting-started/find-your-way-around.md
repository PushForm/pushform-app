## Find any command by name

Press **Ctrl+K** (or **Cmd+K** on macOS) to jump to command search. Type part of a tool or action's name, choose a result with the arrow keys, and press **Enter**. **Escape** closes search without running anything.

Search shows commands for the editor you're in, so a Layout drawing doesn't offer Modeling's Push/Pull.

## Side panels

The menu bar on the left opens these panels:

- **Files**: browse your projects and open files without leaving your drawing.
- **AI Chat**: ask how to do something. It can point out the control you need.
- **Object browser**: see what's in your document and select it.

Opening one panel replaces the one already showing. Drag the panel's right edge to resize it.

## Files and projects

Your documents are kept in projects in the cloud. In **Files**, choose a project, then open folders and files. A file that's already open switches to its tab, keeping any unsaved changes.

Right-click a project, folder or file to **Rename** it, **Move** it or **Move to Trash**. To restore something from the trash, go Home and open **Trash**.

## Undo and cancel

| Action | Windows and Linux | macOS |
| --- | --- | --- |
| Undo | Ctrl+Z | Cmd+Z |
| Redo | Ctrl+Shift+Z or Ctrl+Y | Cmd+Shift+Z |
| Cancel the current tool step | Escape | Escape |

Each document has its own Undo history.

## Go home

Click the PushForm logo to return Home. Your documents stay open, and **Continue working** takes you back to them.
