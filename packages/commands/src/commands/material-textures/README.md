# Material textures

These 30 color maps are from [Poly Haven](https://polyhaven.com), distributed under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
See the [asset license](https://polyhaven.com/license).

Full-size files are the unmodified 1024 × 1024 JPEG diffuse maps. The `-preview.jpg`
files are 128 × 128 JPEG derivatives, resized with Lanczos filtering (quality 85).
Only color maps are used: these are surface-color presets, not a full PBR shader
library. Glass presets are transparent colors without image maps.

The application bundles these files and does not call the Poly Haven API.
Repeat dimensions in the catalog use the source's physical dimensions in meters.
Source download URLs, authors, and SHA-256 checksums are in `sources.json`.
