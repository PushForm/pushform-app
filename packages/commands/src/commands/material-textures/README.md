# Material textures

These 338 color maps are from [Poly Haven](https://polyhaven.com), distributed under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
See the [asset license](https://polyhaven.com/license).

Full-size files retain the source 1K maps' pixel dimensions and aspect ratios,
including rectangular textile maps. They are JPEG derivatives encoded at quality
90 with 4:4:4 chroma and optimized encoding. The `-preview.jpg` files fit within
128 × 128 pixels, resized proportionally with Lanczos filtering (JPEG quality 85).
Only color maps are used: these are surface-color presets, not a full PBR shader
library. Glass presets are transparent colors without image maps.

The application bundles these files and does not call the Poly Haven API.
Repeat dimensions use the source's physical dimensions in meters. Source download
URLs, source categories, authors, source and bundled SHA-256 checksums, and image
dimensions are in `sources.json`. For assets offering multiple color maps, the
map used by the supplied glTF material is included.

The selection uses the 2026-11-01 primary categories. Ceramic, Metal, Textiles
(including leather), Plastic (including rubber), and Organic include every asset
in their respective source categories. The other categories contain a varied
selection of woodworking, building, and landscaping surfaces. Concrete & Asphalt
combines 38 Concrete and 12 Asphalt & Bitumen assets. Each source asset appears once.
